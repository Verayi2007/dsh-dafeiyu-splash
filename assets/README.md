# assets

## feiyu.webp

开屏里那位「大肥鱼娘」的形象图。

- 来源：社区二创的 DeepSeek 鲸鱼娘。形象设定出自 [@ZipZipPipe](https://space.bilibili.com/4168597)，
  社区衍生（含 [ai-chan-sheets](https://github.com/lmy414/ai-chan-sheets)）在其基础上一路迭代；
  本文件取自 [dsh-feiyu-mood](https://github.com/Yuuyuko-uu/dsh-feiyu-mood) 的 `assets/feiyu.png`，
  裁掉透明边、缩到 760px、转成带 alpha 的 WebP（90KB）。
- **许可：CC BY-NC-SA 4.0** —— 署名、非商业、相同方式共享。
  也就是说：这个仓库的**代码**是 MIT，但这张**图**不是 MIT，商用请先换图或另行取得授权。
- 想换成你自己的角色：把同尺寸的透明底 PNG/WebP 放成 `assets/feiyu.webp`，重新 `python tools/build.py` 即可。
